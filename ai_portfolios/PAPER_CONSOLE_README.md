# Claude / GPT 双 Alpaca Paper 面板

本机地址：<http://127.0.0.1:8789/>。本次交付使用 8789；8788 是先前联调版本，请勿同时操作两个版本。

## 现在可以做什么

1. 在“编写指令”分别填写 Claude 和 GPT 的任务，保存草稿。
2. 按“同时开始研究”，或单独运行其中一个模型。单次调用最长等待 10 分钟；一个模型失败不会拿另一个模型的答案代替。
3. 从左侧选择某一轮，查看“本轮输入”。上半部分是你的指令，下半部分是程序实际交给模型 CLI 的完整正文，包括固定规则、行情证据和对应 Paper 账户持仓。
4. 在“原始回复”查看模型的回答；展开日志可看完整 CLI 返回及错误。在“投资建议”查看通过结构检查的建议。
5. 在“持仓与委托”查看 Alpaca 的账户记录。账户数据启动时、每轮研究前和按“刷新账户”时读取；网页每 5 秒更新研究状态，不等于每 5 秒调用券商。

编辑草稿不会改写历史轮次。旧本地模拟记录标注“旧本地观察”，不能当成两个新 Paper 账户的成交或收益。

## 明确的范围

当前是 **账户读取 + AI 研究 + 输入输出追踪**。没有提交、撤销、修改或平仓订单的接口，没有自动调度，没有启用自动交易。生成买入建议不会改变 Paper 持仓。

Alpaca 提供 Paper 账户和市场数据；Claude / GPT 分别由本机已安装的 Claude Code / Codex CLI 调用。Alpaca 密钥不是模型调用凭据。CLI 登录过期要在对应工具重新登录，再单独补跑失败模型。面板不能显示供应商隐藏的系统提示或内部思考，只显示程序发送正文及供应商实际返回内容。

不要求 API 模型订阅迁移：本版本沿用已安装 CLI 的登录方式，具体可用模型、额度和认证以这些工具为准。Claude 的 `sonnet` 是别名，实际返回的版本和用量保存在状态记录中，不能把它当作永远固定的模型版本。

## 启动和停止

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m ai_portfolios.console_server --port 8789
```

也可运行 `ai_portfolios/启动Paper面板.ps1`。服务启动后用浏览器打开上述本机地址。前台启动时按 Ctrl+C 停止；停止或重启会中断未完成研究，重启后的档案会标记中断。电脑关闭后不会继续运行；本版本未安装开机自启。

若地址已能打开，不要再启动一份。不要启动第二份服务同时写入同一实验目录；本版本的运行锁只保护单个服务进程。不要把这个本机面板直接公开到互联网。

## 账户配置

从项目根目录 `.env.aitrading` 读取四个变量；不在网页粘贴密钥：

```text
ClaudeAPCA_API_KEY_ID=<Claude Paper 账户的 key>
ClaudeAPCA_API_SECRET_KEY=<对应 secret>
GptAPCA_API_KEY_ID=<GPT Paper 账户的 key>
GptAPCA_API_SECRET_KEY=<对应 secret>
```

券商地址固定为 `https://paper-api.alpaca.markets`。首次连接后固定模型与账户 ID 的绑定；重复账户、账户被调换会拒绝连接。不会退回旧 AM70/30 账户。

若确实更换账户或重置 Paper 本金，另建实验数据目录并保留旧记录；不要删绑定文件后声称同一条收益曲线连续。当前版本检测 ID 变化，但不能可靠识别所有“同 ID 的账户重置”，需操作者登记。

## 当前共同规则

规则来自 `ai_portfolios/config.json`，是工程实验的默认约束（assumption），不是 Rallies 官方规则，也不是收益最优参数：

- 股票池为配置中的 20 只美股；最多 10 只正仓位，单股目标不超过 20%，总目标仓位不超过 95%。
- 只研究做多股票，可保留现金，不使用杠杆、期权或卖空。
- 模型只能使用本轮冻结的数据，不自行联网搜索。两者共用同一市场证据包，各用自己的账户和上次通过验证的论点。
- 市场数据沿用原有采集器；账户和 Alpaca 数据使用新配置，FMP 配置仍来自原有服务端配置。缺数据必须明确显示，不能声称实时全市场信息。
- 正权重要求同股票的价格证据及新闻或财务证据，并要求论点、退出条件和预计持有天数。结构校验通过 **不代表投资判断正确**。
- 配置里的旧 `initial_cash` 不用于新面板余额；新账户现金和净值只取 Alpaca 返回。
- 预计持有天数是模型意见，不是强制到期卖出。外部人工下单后的变化须刷新账户才可见。

需扩大股票池或改变规则时，修改配置并重启，另行记录实验版本；不要只在 prompt 中要求突破代码限制。账户已有股票不在股票池时，会阻止该账户研究，需明确扩大股票池并补齐其数据。

## 保存位置和审计

本地目录 `reports/ai_paper_console/` 已加入忽略列表，含账户及研究隐私，不要整包公开上传：

- `accounts/<snapshot_id>/`：原始账户、持仓、最近最多 100 笔委托，及记录来源、行数、SHA-256、代码哈希的 `snapshot.json`。
- `rounds/<round_id>/round.json`：当轮用户指令、模型、规则、状态。
- `rounds/<round_id>/accounts_before.json`：当轮账户依据。
- `rounds/<round_id>/packet.json`：共同市场证据；对应采集清单记录来源、观察区间和行数。
- `*_prompt.txt`：程序实际发送正文；`*_response.txt`：正常回复正文；`*_stdout.txt` / `*_stderr.txt`：原始 CLI 返回和诊断；`*_status.json`：结果、用量、校验或失败原因。
- `receipt.json`：完成回执和文件哈希。失败或中断可能没有正常回复文件；界面会显示实际错误，不能补造答案。

账户 API 返回归类 observed（Paper 模拟账户，不是真实资金成交）；由行情计算的特征归类 derived；AI 投资判断和实验限制为 assumption；未获数据为 unknown。程序保留原始回复，不代表证明其中每句话正确。

## 常见问题

| 问题 | 原因及处理 |
|---|---|
| Claude 返回 OAuth / 登录过期 | 在 Claude Code 重新登录，然后点击“只运行 Claude”；保留原失败轮次。Paper 账户已连接不代表 Claude 也已登录。 |
| GPT 额度或模型不可用 | 在 Codex 检查登录和额度；修改可用模型需记录版本后重启。不要伪造回复。 |
| 账户显示连接失败 / 数据不完整 | 检查新 Paper 密钥及权限，按“刷新账户”。缺失持仓显示未知，不按空仓处理。 |
| 修改 prompt 后旧回复没变 | 正常；历史不可改写。点击研究生成新轮次。 |
| 运行后没有成交 | 正常；此版本只生成建议，没有执行模块。 |
| 委托数量少于 Alpaca 全部历史 | 页面只读最近最多 100 笔，不是完整成交账本，不能用它做总收益审计。 |
| 同时运行出现部分失败 | 单独补跑失败模型即可；新的补跑会读取新的市场快照，因此不能声称与上一轮是严格同时间比较。 |

当前没有完整的入出金调整、净值曲线、费用归因、SPY/QQQ 收益比较；上方“较上日净值”只是两个账户字段相减，不是本实验累计利润。账户数据未自动成交前，不能用这个面板证明任一 AI 的赚钱能力。

## 若下一步接自动 Paper 执行

应新增独立执行模块，先定义订单审批方式、调度频率和风控，不把读账户研究函数改成偷偷下单。至少验证：Paper 域名硬锁定、模型目标转订单的差额计算、市场交易时段、最新报价、现金/股数限制、重复启动幂等、部分成交、取消与补单、重启后券商对账、人工交易冲突、失败停止和审计。执行模块必须以券商成交回报为账本，不能从模型文字生成假成交。

本指南不授权或启动真实资金交易。
