# Paper console design

- A practical research desk: warm ivory background, forest-green navigation, restrained copper for Claude.
- Main workflow: separate Alpaca account cards, chronological research archive, editable instructions, exact frozen input, unedited response, broker records.
- All user/model text renders as text, never executable HTML.
- Responsive panels use system Chinese fonts and monospace for timestamps and source records; no external fonts or trackers.
- Distinguish a recommendation, a submitted broker order, and a fill. Historical shadow records must retain their own label.
